# Unified scALABLE analysis

Authorized request: Supervised, Unsupervised or Both in one scALABLE-web workflow, with differential analysis in every mode, one union h5ad for Both, and a barcode association dot plot. The standalone discover app remains available.

The Analysis selector belongs to **1. Upload**, between Species and Reference. Its value is recorded during upload, restored with saved jobs, and transmitted again with QC. Unsupervised hides the reference field/preview and does not require a reference to upload; the ICGS3 settings remain in **2. QC**. Cleanup recreates a missing configured storage root and tolerates an expired job removed concurrently by another process, preventing those conditions from rejecting a new upload.

1. **Supervised:** call the existing `run_cellharmony_pipeline` unchanged by default: cellHarmony-lite QC/ambient correction/alignment, MarkerFinder, approximate reference UMAP, selected standard imputations and fastComm. Existing differential implementation and 500-cell/state/sample cap remain in force.
2. **Unsupervised:** use the existing cellHarmony-lite QC-only call, persist its normalized matrix and counts/ambient layers, and run the existing discover pipeline through `ICGS.run_icgs3` with discover's documented configuration. Shared QC is not ambient-corrected again. Differential options are enabled using the actual sample annotations and ICGS3 assignments.
3. **Both:** shared QC once, then the standard supervised branch and the standard ICGS3 branch sequentially. Their outputs live in separate branch directories. The final h5ad uses shared QC expression, counts, features and source annotations, selected by the exact union of accepted cell barcodes. It holds `supervised_state`, `unsupervised_cluster`, `unsupervised_state`, acceptance flags, alignment/ICGS3 annotations, and separate supervised/unsupervised UMAPs. No coordinate spaces are averaged. Missing assignments are explicitly `Unaligned` or `Not clustered`; missing coordinates remain missing. Both branch rosters must be unique subsets of shared QC and preserve its complete ordered feature roster before the output is written.
4. **Explore:** a job-specific cell-state layer selection supplies markers, communication and Chat readers with the matching branch metadata. Color and annotation controls can inspect both assignments. Coordinate axes can switch embeddings. Imputations retain the standard supervised branch's coverage; unaligned cells are not assigned fabricated molecular predictions.
5. **Associations:** X = ICGS3 cluster, Y = supervised state, including Unaligned/Not clustered. One dot counts shared barcodes, area = count, color = percent of that unsupervised cluster. Annotation filters apply before the denominator is calculated. A complete TSV accompanies the figure. This is a descriptive contingency plot, not a biological-replicate statistical comparison or independent annotation validation.
6. **Differential:** every mode calls the existing differential pipeline. Both exposes the two assignment systems as population fields; comparisons and their output identifiers retain the chosen population column. More than five selected sample values still defaults to pseudobulk; both comparison types retain the existing random 500-cell/state/sample cap.

## Both display and result controls — 2026-10-07

- Fresh Both sessions default to supervised assignments and their native coordinates in panel 1, and unsupervised clusters and their native coordinates in panel 2. Subsequent user choices are preserved.
- The union includes unaligned cells. A cell lacking a supervised coordinate is counted explicitly in that plot; a button switches to its saved unsupervised coordinates while retaining supervised colors. Coordinate systems are never spliced or fabricated.
- RNA and imputed sidecars select branch embeddings by barcode, including reordered sidecars. Prediction coverage is unchanged; this software fix does not generate new predictions for unaligned cells.
- Differential population fields identify supervised states, unsupervised clusters and unsupervised states. Generated assignment/acceptance fields cannot masquerade as sample groups. Saved comparison labels identify the population field; edited settings clear obsolete result links and preserve saved history.
- Model provenance is appended to Download log. Separate provenance controls are removed. Both hides the separate unaligned-cell download because those cells are in its combined file.
- Native cellHarmony and ICGS3 stages are retained through worker, API and browser reporting. Both's QC form/status do not shrink onto each other; the log uses the remaining panel space.
- Validation distinguishes read-only saved-job UI/API checks from synthetic modality fixtures. These software checks do not resolve the prior pending scientific coverage question or authorize a new inference run.
