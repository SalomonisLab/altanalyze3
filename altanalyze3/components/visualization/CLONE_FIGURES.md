# Clonal prediction and Figure 4 workflows

The reviewed `detection-tree` model and `no-mutant-call-WT-v1` policy are unchanged. New visualizers are now callable AltAnalyze3 modules rather than session scripts. All input cells/events remain in inference. WT is an operational no-accepted-mutant-call category, not proof of genome-wide normality.

## Defaults

`python -m altanalyze3.components.bam.clonal_inference.detection_plotting --result RESULT --input INPUT --output OUT` exports the existing eight standard plot types (sensitivity requires `--sensitivity-root`), **plus** the compact source heatmap and clinical cell-state/clone alluvial by default. `--legacy-vector-only` explicitly replays the historical standard suite. Original vector source heatmaps are still available; the default compact companion uses a 600 dpi raster layer with 0.15 pt marks and editable vector text.

`python -m altanalyze3.components.visualization.clone_figure_workflow --manifest manifest.json --output OUT` orchestrates saved-fit reporting for every declared patient, evidence rings, exact UMAP matching, native AltAnalyze2 rendering and companion clone/timepoint panels. `--section clones|rings|umap` permits independent scheduled jobs; `--patient` selects a declared patient, never cells inside a patient. Reports have separate filenames for each scheduled unit. `--refit` explicitly reruns the unchanged default model against the current fit contract. Submit real fits and figure suites with bsub; the notebook provides launch commands. No external shell command is constructed from input metadata.

## Visualization commands

All commands are registered under `altanalyze3 visualize`; their modules also support `python -m`:

- `clone-source-heatmap`: `--input INPUT --figures FIGURES --output OUT`. One mutation name per complete evidence group; modality color strip; MUT wins only for the conflict display, while original source codes are retained. Clone widths use maximum reporting assignments, not fractional mixture weights. All samples, including grafts, remain.
- `clone-alluvial`: `--figures FIGURES --output OUT [--config CONFIG] [--aggregation fine]`. U cells are excluded by default (`include_unassigned=False`); `--include-unassigned` restores them. WT remains. Displayed frequencies and n use assigned cells when U is excluded; complete source assignments and excluded-cell tables are retained. Grafts are audited separately, never joined into the clinical time axis. Unknown states are retained. With no config, original states remain separate. The published broad preset is `presets/kinnex_5801_broad_states.json`: HSC/MPP-1/2 together, MPP-MEP separate, MEP-Eryth and Erythroblasts within ERP. Sample names/counts and presentation choices are explicit. Connectors have half-width and a 50% white mask; aligned side bars use state and clone colors. Ribbons are frequency interpolation, not traced-cell transitions.
- `clone-umap-map`: `--coordinates COORDS --figures FIGURES --config CONFIG --output OUT`. Exact library plus reverse-complement barcode only. Retains every coordinate cell and every input KINNEX cell in separate complete-roster tables. Unmatched cells never become WT. The JSON config declares healthy libraries, library/timepoint labels and permitted stage-name normalization.
- `clone-umap`: `--inputs MAPPED --expression EXP --coordinates COORDS --altanalyze2 AltAnalyze.py --python2 PYTHON --output OUT`. **Native AltAnalyze2 is the default renderer.** Its external install and Python 2 environment are required. On CCHMC load `python/2.7.5` (including tk/cairo libraries); preserve that LD_LIBRARY_PATH when also invoking Python 3. The wrapper adds SVG and verifies all actual plotted coordinates/group counts. It neither recomputes UMAP nor modifies AltAnalyze2.
- `clone-umap-panels`: explicit companion individual-clone and timepoint overlays on the same coordinates; not a replacement for the native AA2 figure. Gray backgrounds retain all unhighlighted/unmatched cells.
- `variant-evidence-workflow`: `--root ROOT --output OUT [--include-loy] [--label-items DNMT3A-R882C]`. Reads complete step-04 summary/unit/evidence tables. The approved ring arithmetic is preserved. Label selection never removes variants or changes ring areas. LOY, when explicitly included, is labeled short-read CNV evidence and has a different cell universe. The generic `evidence-rings` command remains available.

## Reproducibility and validation

The Figure 4 notebook and manifest live in KINNEX-5/Jupyter/Figure4. The archived code snapshot supports reproduction of uncommitted local changes; source SHA-256, full input contracts, baseline comparisons and environment versions accompany it. The notebook opens saved results by default and requires explicit `RUN_LSF=True` for expensive reruns. Panel a is supplied clinical-history artwork, not an output of clone inference. Panels b–f are linked to their analysis and renderer sources; the notebook is Figure 4 as requested even though the supplied artwork filename starts Fig.5.

Scientific limits: clone tree development used known 5801 biology and is not independent validation. Source heatmaps/alluvials use discrete maximum memberships; fishplots use fractional reporting memberships. They need not have identical clone percentages. Neither rendered curves nor normal-looking transcriptomes prove lineage ancestry or genome-wide WT status. No statistical tests or confidence intervals are introduced by these adapters.

## Broad-state presets across patient series

`presets/kinnex_broad_lineages.json` extends the approved lineage mapping to all represented clinical states, including BMCP-2, MK-Platelet, immNeu-2 and additional T/B subtypes. MKP / MK and BMCP labels explicitly describe the broader groups. Patient sample rosters, counts and timepoint labels remain in individual configuration files. The archive manifest `manifest_broad_states.json` applies these mappings to all six series while preserving earlier fine-state outputs. No clone fitting or WT-policy change is involved.

## Saved final-revised-1 reporting and print layout

Set a patient manifest entry `reporting_workflow` to `final-revised-1` to render saved minimum-supported-lineage reports without rerunning or substituting inference. This uses `clone_lineage_figures.render`, with `include_unassigned=False` by default for heatmap, fishplot and alluvial. Counts, denominators, exclusions and per-cell membership are audited. `--include-unassigned` restores all-cell reporting. An empty assigned specimen raises an error rather than being dropped. Source fit and assignment tables are read-only.

The standalone `clone_review_panel` composer makes a 612 × 396 pt SVG/PDF half-page with a/b on the left and c/d on the right. All editable text is at least 5.05 pt after placement; tree node positions adapt to the half-page while circles remain round. Other panel axes can be resized independently while labels retain their physical font sizes. It preserves plot paths and embedded heatmap pixels, removes duplicated panel legends, provides a shared caption, and audits page bounds and font sizes. Small overlapping clone labels are omitted without removing bands. It requires Playwright and Chromium/Chrome; set `ALTANALYZE_CHROME` if needed. Saved-lineage rendering composes this page by default; set manifest `review_panel: false` for a headless cluster render followed by local composition.
